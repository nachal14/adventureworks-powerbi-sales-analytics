# Adventure Works Sales Analytics – Power BI

## 📊 Project Overview

An interactive Power BI solution built to analyze Adventure Works' sales trends, regional performance, and product profitability. The project transforms raw business data into actionable insights for better decision-making.

## 🎯 Business Objectives

* Track sales and profitability trends
* Identify regional performance gaps
* Analyze product-level contribution
* Monitor YoY and MoM performance
* Support data-driven inventory and marketing decisions

## 🛠️ Tools & Skills

* Power BI
* Power Query
* DAX
* Data Modeling
* Star Schema
* Data Cleaning & Transformation
* Row-Level Security (RLS)
* Power BI Service
* Data Visualization
* Business Analysis

## 🔧 What I Built

* Cleaned and transformed sales, customer, and product data using Power Query.
* Designed a star-schema data model with optimized relationships.
* Developed DAX measures for YoY/MoM growth, product ranking, and regional contribution.
* Built interactive dashboards with KPIs, maps, trend analysis, drill-through pages, and custom tooltips.
* Implemented Row-Level Security (RLS) for controlled stakeholder access.
* Published the solution through Power BI Service.

## 🔍 Key Business Insights

* Identified a significant YoY sales decline in the Southwest region, highlighting an area requiring strategic review.
* Found that approximately 20% of products generated the majority of revenue, helping prioritize inventory and marketing efforts.
* Created a centralized reporting solution that improves visibility into sales and profitability performance.

## 📈 Dashboard

The dashboard provides an interactive view of:

* Sales & Profit KPIs
* Regional Performance
* Sales Trends
* Product Performance
* Customer Analysis
* YoY/MoM Growth
* Product Contribution

## 🧠 Key Takeaways

This project demonstrates the ability to move beyond dashboard creation by combining:

**Data Cleaning → Data Modeling → DAX → Visualization → Business Analysis → Actionable Insights**

The focus was not just on presenting numbers, but on identifying business problems and translating data into decisions.
